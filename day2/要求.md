# 实验四

1. 请设计一个按键切换 LED 灯亮灭的装置，当初次按下按钮
   开关， LED 灯点亮，再次按下按钮开关， LED 灯熄灭，再按下按钮， LED 灯又亮
   起，再按下又熄灭，如此反复。请用 Arduino IDE 程序或 mind+ 程序实现。[led_turn_on.c](p1/led_turn_on.c)
2. 在实用按键控制 LED 实验基础上，设计一个延时灯，当按下按钮开关后，
   LED 灯点亮，保持 6秒钟后，自动熄灭。[led_auto_extinguish.c](p1/led_auto_extinguish.c)
3. 请设计一个按键切换 LED 灯亮灭的装置，当按 一下按钮开关， LED 红灯点亮
   （绿灯熄灭状态） ，双击 按钮开关 LED 绿灯点亮（红灯同时熄灭） ，长按按钮 ，
   所有 LED 灯熄灭。请用 Arduino IDE 程序或 mind+ 程序实现。[led_exchange.c](p1/led_exchange.c)

# 实验五

1.请设计一个双控开关控制 LED 灯的装置，实现处于不同 位置的两个按钮控制一个 LED 灯的目的。当一个按键点亮 LED 灯后，可用另一
个按钮关掉 LED 。请用 Arduino IDE 程序或 mind+ 程序实现 。[led_double_swtich.c](p2/led_double_swtich.c)
2.请设计一个交互式流水灯装置，通过按钮控制流水灯的方向与速度，实现动 态交互。要求按钮 A切换流水灯方向（左 →右或右 →左），按钮
B调整流水速度 （快、中、慢三档），速度变化需平滑过渡。[led_interact.c](p2/led_interact.c)
